## 请求费用预估

`POST https://api.xybcloud.com/api/pricing/quote` 使用本人 `Authorization: Bearer YOUR_API_KEY`。报价不会提交生成任务、请求上游生成、扣款或写入任务记录。不得将接口当作最终账单或额度预留。

```json
{
  "endpoint": "/v1/images/generations",
  "body": {
    "model": "你有权使用的实际模型ID",
    "prompt": "明亮的产品摄影",
    "n": 1,
    "quality": "medium",
    "size": "1536x1024"
  },
  "batch_count": 3
}
```

该例是三次各生成一张图片的请求。若实际提交是一次 `n=3`，应改成 `body.n=3`、`batch_count=1`。每次请求的配额舍入与批量汇总顺序可能影响极小金额，二者不能随意互换。

`endpoint` 仅支持以下路径，不可传完整URL、查询串或其他目标：

- `/v1/images/generations`
- `/v1/images/edits`
- `/v1/videos`
- `/api/v3/contents/generations/tasks`
- `/v1/chat/completions`
- `/v1/audio/speech`
- `/v1/responses`

`body` 是实际模型请求的 JSON 描述，`model` 必填。`batch_count` 为1–20的整数；整个报价请求不超过1MiB。上传素材、模型参数规范化和批量拆分应与真正发送时保持一致。不要把客户端图片宽高比直接当作已经规范化的像素尺寸，也不要按模型名猜测固定的时长或清晰度倍率。

用户身份、模型权限、分组、个人优惠、渠道与计价规则由服务端确定。客户端不能传入最终额度、个人折扣、上游凭据等计费权威字段。

## 返回语义

外层为 `{success: true, data: ...}`。`data` 的主要字段：

| 字段 | 含义 |
| --- | --- |
| `status` | `estimated`、`usage_required` 或 `unavailable` |
| `quota` | 本次预计账本额度，可为 null；不是美元或人民币金额 |
| `quota_per_unit` | 本次换算所依据的账本单位 |
| `model` | 原请求模型 |
| `group` | 当前选定的计费组 |
| `billing_mode` | 计价模式 |
| `billing_revision` | 当前规则标识，部分旧任务模式可能无标识 |
| `batch_count` | 已纳入报价的外层请求次数 |
| `missing_fields` | 缺少的请求参数或未来实际用量 |
| `unit_rates` | 可可靠拆分的单位额度列表，元素含dimension、quota、per、unit、conditional |
| `message` | 报价边界说明 |

- `estimated`：按当前可知参数及本人价格计算；实际返回用量、部分失败、参数覆盖或重试路由仍可能影响最终结算。
- `usage_required`：输出Token、音视频实际用量等尚未产生，`quota=null`。可展示返回的单位积分和待确定项，不能将空额度显示成0积分。
- `unavailable`：未知插件、未支持协议、配置覆盖或其他不能可靠推算的组合。应显示暂无法报价，不能套用其他模型、渠道或公共单价。

真实0价格与无法报价是两种状态。只有有效数值0才能显示预计0积分。非线性/条件表达式不能可靠拆分单位价时，`unit_rates` 可以为空。

豆包 Seedance 任务只有在没有参考视频、显式时长大于0且不超过15秒、显式分辨率为480p/720p/1080p，且插件估算Token符合当前计算规则时，才返回条件性 `estimated`。该估算使用插件按分辨率、24帧/秒和时长计算的输出用量，仍须以最终实际用量结算。参考视频的输入时长等信息不足时返回 `usage_required`，不能沿用纯文生视频的总额。

## 工作台积分口径

鑫元宝视频工作台使用与钱包相同的额度换算：

```text
预计积分 = quota / quota_per_unit × 10
```

此处的10来自本站工作台积分定义。不要先按显示币种换汇再换积分；`quota_display_type` 和美元汇率不改变这条积分账本换算。单位价也用同一公式换算，但保留其 `per` 与 `unit`，不能把“每千Token”当成“每次”。

个人优惠已包含于返回额度，不要再乘一次优惠系数。批量总额已包含于 `quota`，也不要再次乘 `batch_count`。

例如客户端拿到有效 `quota` 和 `quota_per_unit` 后，先校验非负、有限值及单位大于0，再换算。显示微小正数时保留足够精度，禁止四舍五入成免费。

## 客户端交互

模型、质量、分辨率、时长、声音开关、参考素材、数量、用户身份或渠道变化后重新报价。取消旧请求，避免迟到结果覆盖新的参数。不要持久缓存其他账号的报价，也不要把鑫元宝个人报价应用于用户自有供应商渠道。

`GET /api/pricing/self` 是本人价表，适合模型选择器展示单位参考价；它不是带完整任务参数的总费用。请求级总额使用本页报价接口。文本输出和视频实际用量未产生时，界面应说明最终按实际用量结算。

本接口不更改实际计价规则。真正请求的计费、扣款、退款和账单仍以生成调用链为准。
