## 🚀 统一接入参数

对话等标准接口可使用 **OpenAI 兼容协议**。视频任务、真人素材授权与管理需要按各自接口接入，通用 OpenAI 客户端不会自动具备这些功能。可用模型以当前用户 API Key 查询结果为准。

- [真人素材与第三方客户端接入](/zh/docs/api/real-person-assets)：H5 本人授权、图片/视频/音频入库、Seedance 引用及浪起客户端接入。
- [请求费用预估与积分换算](/zh/docs/api/request-pricing)：按本次参数和本人权限预估，区分固定计价与实际用量。

```http
# 基础请求地址 (Base URL)
API Base URL: https://api.xybcloud.com/v1

# 请求认证头部 (Header)
Authorization: Bearer sk-xxxxxxxxxxxxxxxxxxxxxxxx
```

## ⚡ 三步极速接入

1. **获取 API 令牌**：登录 [控制台](https://api.xybcloud.com/keys)，进入「令牌管理」生成您的专属 API Key；
2. **配置请求终端**：将客户端（如 Cherry Studio / Cursor / Claude Code）或代码中的接口地址设为 `https://api.xybcloud.com/v1`；
3. **选择模型发起调用**：指定模型名称（如 `gpt-4o`、`claude-3-7-sonnet`、`deepseek-chat`、`gemini-2.5-pro`），即刻享受稳定高并发算力。

## 💻 快速调用代码示例

### Python (使用官方 `openai` 库)

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY", # 替换为您在控制台生成的 API Key
    base_url="https://api.xybcloud.com/v1"
)

response = client.chat.completions.create(
    model="deepseek-chat", # 或 gpt-4o / claude-3-7-sonnet 等
    messages=[
        {"role": "system", "content": "你是一位专业的 AI 助手。"},
        {"role": "user", "content": "你好，请简单介绍一下自己。"}
    ],
    stream=True # 支持极速打字机流式输出
)

for chunk in response:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
```

### Node.js / TypeScript

```javascript
import OpenAI from "openai";

const openai = new OpenAI({
  apiKey: "YOUR_API_KEY",
  baseURL: "https://api.xybcloud.com/v1",
});

async function main() {
  const completion = await openai.chat.completions.create({
    model: "gpt-4o",
    messages: [{ role: "user", content: "请用一句话概括云计算的价值。" }],
  });

  console.log(completion.choices[0].message.content);
}

main();
```
